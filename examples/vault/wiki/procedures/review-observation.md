# Review a sample observation

Use this procedure before using a fictional observation in a comparison.

1. Open its preserved source.
2. Match the value, period, and population definition.
3. Check whether another selected record overlaps its universe.
4. Preserve unavailable values as missing.[^report]

The expected result is a documented compatibility decision. This procedure does not verify actual population data or authorize unrelated actions.

[^report]: [Demonstration report](../sources/fictional-report.md), Section C.
