# Fictional worked example

Everything in this vault is invented for testing and explanation. Harbor Association, the authors, theories, observations, and report are fictional. No figures describe an actual population.

The example demonstrates two different explanations for institutional continuity, source attribution, a human-owned hypothesis, membership counts with different universes, a missing value, a measured zero, and a model using canonical observations.

Open vault/ in Obsidian and start at wiki/index.md. Or use the commands in the project README. The source file is deliberately short enough to verify every quote and locator manually.

For the membership records, adult membership and all-age membership overlap. They must not be added. The model compares only the two all-age records and contains a formula specification rather than a generated result.
