# Personal observations

Store dates, setup identity, units, measurement method, interventions, and relevant conditions. Use observation JSON for values requiring exact filtering and human-owned notes for context.

Distinguish a measured zero, an unavailable value, a threshold result, and a missing measurement. Record instrument or method changes.

An intervention preceding a change is a temporal observation. It does not establish causation. Link proposed explanations as hypotheses.

Preserve originals and corrections as versions when they matter to interpretation. Do not silently rewrite past logs into a cleaner story.

Personal records and identifying setup information stay in .local.
